# Stop View (iOS app) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tapping any stop on the map (or a stop search result) opens a stop view listing everything leaving that stop; the map shows a fixed centre marker, the mode's radius and every stop around it.

**Architecture:** Two new `@MainActor` models join the existing ones: `StopModel` (one stop's departures from `/departures`, 30 s refresh, pause under route focus and in the background, last-good rows) and `StationStore` (Luas and train station lists from `/stations`, one fetch per mode per session, falling back to `/nearby`'s stops). `HomeModel.Screen` gains `.stop(StopTarget)`; the stop view sits between the timeline and route focus, saving and restoring the camera the way focus does, and focus opened from a stop view returns to it. `HomeView` draws a non-hit-testing `CentreMarker` and a `MapCircle` of the mode's radius in the timeline, pins per mode, and a new `StopView` panel built from `DepartureCard`. Each model is fed by a small `Sendable` protocol that `TurasServerService` implements and tests fake, with time injected as `AppClock`.

**Tech Stack:** Swift 5.9 language mode, SwiftUI + MapKit (`Map`, `Annotation`, `MapCircle`), Combine (`@Published`), XCTest + XCUITest, XcodeGen. No third-party dependencies.

**Spec:** `/Users/markbradley/Code/Turas/docs/superpowers/specs/2026-10-12-stop-view-design.md` (read it; this plan implements its "User experience" and "App changes (`turas`)" sections and the app parts of "Testing", "Delivery" and "Risks and notes"). The server's `/stations`, `/departures` and changed `/nearby` are a separate plan; the JSON in the spec is the exact contract.

**Spec deviations** (settled here, each noted in the task that implements it):
- A stop view has **one mode** (`StopTarget.mode`): the tab's mode for a pin; for a stop search result, the tab's mode when the stop serves it, else the stop's own first mode. The tab is not changed by a search result. The server's rows carry no mode, and a stop serves one mode in TFI's feed (Luas, rail and bus stop IDs are disjoint), so this is enough to colour badges and choose the focus endpoint. (Task 1, Task 7.)
- A **404** clears the rows and ends polling, and its banner has no Retry: a stop that left the timetable has nothing to show and nothing to retry. The spec names only the message. (Task 4.)
- The **near-me button** is hidden in the stop view, as it is in route focus: the map belongs to the stop. The spec is silent. (Task 8.)
- The timeline's **empty message** names the mode's radius ("Nothing leaving within 300 m …" / "800 m"), replacing the old 500 m copy. (Task 5.)
- The route focus back button is labelled **"Back to stop"** (VoiceOver) when focus came from a stop view. (Task 6, Task 8.)
- `DepartureCard` takes an **identifier prefix** so stop view rows are `stop.row.<id>` and timeline rows stay `timeline.row.<id>` for UI tests. (Task 6.)
- The server PR may regenerate **`nearby.json`** (its `stops` now lists every stop in the radius); the fixture task copies it too if it changed. (Task 10.)

## Review Focus

Situations the spec is silent on, most likely to bite first. Each has a test in the task named.

1. **Backgrounded for hours in a stop view, or under route focus over it** — on return the stop view fetches immediately and the stale rows stay with "Updated N min ago"; a background/foreground cycle while route focus covers the stop view must not wake the stop's loop (two loops would double the load and race). (Task 4, `testBackgroundPausesAndForegroundFetchesImmediately`, `testPauseForFocusSurvivesSceneChanges`.)
2. **Tapping a second pin before the first stop's answer arrives** — the first answer never shows and the first model stops polling; the timeline stays paused across the switch and its saved camera still wins on back. (Task 7, `testTappingAnotherPinSwitchesStopAndStopsTheOldOne`.)
3. **A pin tapped before the timeline's first fetch landed** (fast tap at launch) — back must still fetch the timeline where the map is, never leave it blank. (Task 7, `testStopOpenedBeforeTheFirstFetchStillFetchesOnBack`.)
4. **`/stations` fails or answers an empty list on the first Luas or train selection** — the map falls back to `/nearby`'s stops as pins, the next selection of that mode fetches again, and bus never asks for stations. (Task 3, `testFailureLeavesNothingAndTheNextLoadRetries`, `testEmptyListCountsAsNotLoaded`; Task 7, `testLuasPinsComeFromStationsAndFallBackToNearbyStops`.)
5. **A stop with no `stop_code` and no location authorisation** — the header caption is absent, never "Stop " alone or a dangling " · "; and **a stop search result for a mode other than the tab** opens the stop view as the stop's own mode without changing the tab. (Task 4, `testCaptionAndDistance`; Task 7, `testStopResultOpensTheStopViewDirectly`.)

Also pinned in their owning tasks: 404 ends polling and clears rows (Task 4), 503 retries and 429 is silent (Task 4), a stop reached by search that is not among the map's pins still gets a highlighted pin (Task 8), the covered timeline is hidden from accessibility while the stop view shows (Task 9), and a Luas station's merged ID as a focus stop not in the route's stop list (existing `RouteFocusModelTests.testRequestedStopMissingFromListIsStillUsed`).

```swift
import CoreLocation
import Foundation

/// A Luas or train station for the map (GET /api/v1/stations): one entry
/// per Luas stop (the server merges its two platforms into the lower stop
/// ID) or train station.
struct Station: Decodable, Identifiable, Hashable, Sendable {
    let id: String
    let name: String
    let lat: Double
    let lon: Double

    var coordinate: CLLocationCoordinate2D {
        CLLocationCoordinate2D(latitude: lat, longitude: lon)
    }
}

/// The stop a departures answer describes.
struct StopInfo: Decodable, Hashable, Sendable {
    let id: String
    let name: String
    /// The public stop number ("7602"); nil when the feed has none (the
    /// server omits an empty code).
    let code: String?
    let lat: Double
    let lon: Double
    /// Modes of the routes serving the stop; unknown names are dropped.
    let modes: [TransportMode]

    init(id: String, name: String, code: String?, lat: Double, lon: Double, modes: [TransportMode]) {
        self.id = id
        self.name = name
        self.code = code
        self.lat = lat
        self.lon = lon
        self.modes = modes
    }

    init(from decoder: Decoder) throws {
        let container = try decoder.container(keyedBy: CodingKeys.self)
        id = try container.decode(String.self, forKey: .id)
        name = try container.decode(String.self, forKey: .name)
        let rawCode = try container.decodeIfPresent(String.self, forKey: .code) ?? ""
        code = rawCode.isEmpty ? nil : rawCode
        lat = try container.decode(Double.self, forKey: .lat)
        lon = try container.decode(Double.self, forKey: .lon)
        let rawModes = try container.decodeIfPresent([String].self, forKey: .modes) ?? []
        modes = rawModes.compactMap(TransportMode.init(rawValue:))
    }

    private enum CodingKeys: String, CodingKey {
        case id, name, code, lat, lon, modes
    }
}

/// Everything leaving one stop (GET /api/v1/departures). The rows have
/// the `/nearby` shape, with `distance_m` 0 and `stop_id` the requested
/// stop; a missing or null list decodes as empty.
struct StopDepartures: Decodable, Equatable, Sendable {
    let stop: StopInfo
    let departures: [NearbyDeparture]

    init(stop: StopInfo, departures: [NearbyDeparture]) {
        self.stop = stop
        self.departures = departures
    }

    init(from decoder: Decoder) throws {
        let container = try decoder.container(keyedBy: CodingKeys.self)
        stop = try container.decode(StopInfo.self, forKey: .stop)
        departures = try container.decodeIfPresent([NearbyDeparture].self, forKey: .departures) ?? []
    }

    private enum CodingKeys: String, CodingKey {
        case stop, departures
    }
}

/// What the stop view was opened for: a pin on the map or a stop search
/// result. A stop view has one mode (the rows carry none, and a stop
/// serves one mode in TFI's feed): it colours the badges and picks the
/// route focus endpoint.
struct StopTarget: Identifiable, Hashable, Sendable {
    let id: String
    let name: String
    let lat: Double
    let lon: Double
    let mode: TransportMode

    init(id: String, name: String, lat: Double, lon: Double, mode: TransportMode) {
        self.id = id
        self.name = name
        self.lat = lat
        self.lon = lon
        self.mode = mode
    }

    /// A bus pin, from `/nearby`'s stops.
    init(_ stop: DepartureStop, mode: TransportMode) {
        self.init(id: stop.id, name: stop.name, lat: stop.lat, lon: stop.lon, mode: mode)
    }

    /// A Luas or train station pin.
    init(_ station: Station, mode: TransportMode) {
        self.init(id: station.id, name: station.name, lat: station.lat, lon: station.lon, mode: mode)
    }

    /// A stop search result: the current mode when the stop serves it,
    /// else the stop's own first mode, else the current mode.
    init(_ result: StopSearchResult, preferring mode: TransportMode) {
        let stopMode = result.modes.contains(mode) ? mode : (result.modes.first ?? mode)
        self.init(id: result.id, name: result.name, lat: result.lat, lon: result.lon, mode: stopMode)
    }

    var coordinate: CLLocationCoordinate2D {
        CLLocationCoordinate2D(latitude: lat, longitude: lon)
    }
}
```

```swift
import Foundation
import os

/// Every Luas and train station, for the map pins: fetched from
/// `/stations` the first time a rail mode is selected and kept for the
/// session. A failed (or empty) answer is dropped, so the map falls back
/// to `/nearby`'s stops and the next selection of the mode asks again.
@MainActor
final class StationStore: ObservableObject {
    @Published private(set) var stations: [TransportMode: [Station]] = [:]

    private let source: StationSource
    private var tasks: [TransportMode: Task<Void, Never>] = [:]

    private static let logger = Logger(subsystem: "com.turas", category: "StationStore")

    init(source: StationSource) {
        self.source = source
    }

    /// The mode's stations, or nil until they are loaded.
    func stations(for mode: TransportMode) -> [Station]? {
        stations[mode]
    }

    /// A fetch for the mode is in flight.
    func isLoading(_ mode: TransportMode) -> Bool {
        tasks[mode] != nil
    }

    /// Fetches the mode's stations unless they are loaded or loading. Bus
    /// has ~10,000 stops and is never fetched: its pins come from `/nearby`.
    func load(_ mode: TransportMode) {
        guard mode != .bus, stations[mode] == nil, tasks[mode] == nil else { return }
        let source = source
        tasks[mode] = Task { [weak self] in
            do {
                let list = try await source.fetchStations(mode: mode)
                if list.isEmpty {
                    Self.logger.error("No \(mode.rawValue) stations listed; using nearby stops")
                } else {
                    self?.stations[mode] = list
                }
            } catch {
                if !ServerErrorText.isCancellation(error) {
                    Self.logger.error("Station fetch failed for \(mode.rawValue): \(error.localizedDescription)")
                }
            }
            self?.tasks[mode] = nil
        }
    }
}
```

```swift
import CoreLocation
import Foundation
import os
import SwiftUI

/// Everything leaving one stop, refreshed every 30 s while the stop view
/// is open and in the foreground. Route focus over the stop view pauses
/// it; closing focus resumes it with a fetch. A failed refresh keeps the
/// last rows; a 404 means the stop left the timetable and ends polling.
@MainActor
final class StopModel: ObservableObject {
    /// What the stop view shows besides its rows.
    enum Status: Equatable {
        /// Nothing fetched yet; the first request is pending or in flight.
        case loading
        /// Rows are current.
        case loaded
        /// The server answered with no departures.
        case empty
        /// The server is still loading its schedule (503); retried automatically.
        case starting
        /// The last refresh failed; `departures` is the last good answer, if any.
        case failed(message: String)
        /// The stop is no longer in the timetable (404); polling has stopped.
        case gone
    }

    static let refreshInterval: Duration = .seconds(30)
    static let emptyMessage = "Nothing leaving in the next 90 minutes"
    static let goneMessage = "This stop is no longer in the timetable"

    let target: StopTarget

    /// The stop as the server describes it (name, code), once it has answered.
    @Published private(set) var info: StopInfo?
    @Published private(set) var departures: [NearbyDeparture] = []
    @Published private(set) var lastUpdated: Date?
    @Published private(set) var status: Status = .loading

    private let source: StopSource
    private let clock: AppClock
    private let userLocation: CLLocationCoordinate2D?
    private var refreshTask: Task<Void, Never>?
    private var generation = 0
    /// Between `start()` and `stop()`.
    private var isStarted = false
    /// `stop()` was called; a later `start()` does nothing (the stop view
    /// can close before the task that starts it runs).
    private var isStopped = false
    /// The scene is in the foreground.
    private var isForeground = true
    /// Route focus is open over the stop view.
    private var isPaused = false
    /// The server answered 404.
    private var isGone = false

    private static let logger = Logger(subsystem: "com.turas", category: "StopModel")

    init(target: StopTarget, userLocation: CLLocationCoordinate2D?, source: StopSource, clock: AppClock = .system) {
        self.target = target
        self.userLocation = userLocation
        self.source = source
        self.clock = clock
    }

    /// The server's name once known, else the pin's or result's.
    var name: String { info?.name ?? target.name }

    /// Straight-line metres from the user to the stop; nil without a location.
    var distanceFromUser: Int? {
        guard let userLocation else { return nil }
        let metres = GeoUtils.straightLineDistance(lat1: userLocation.latitude, lon1: userLocation.longitude, lat2: target.lat, lon2: target.lon)
        return Int(metres.rounded())
    }

    /// "Stop 7602 · 240 m", either part alone, or nil with neither.
    var caption: String? { Self.caption(code: info?.code, distanceMetres: distanceFromUser) }

    nonisolated static func caption(code: String?, distanceMetres: Int?) -> String? {
        var parts: [String] = []
        if let code, !code.isEmpty {
            parts.append("Stop \(code)")
        }
        if let distanceMetres {
            parts.append(DepartureFormatting.distanceText(metres: distanceMetres))
        }
        return parts.isEmpty ? nil : parts.joined(separator: " · ")
    }

    /// The stop to highlight when a row opens route focus.
    var focusStop: FocusStop {
        FocusStop(id: target.id, name: name, lat: target.lat, lon: target.lon)
    }

    // MARK: - Lifecycle

    /// Fetches once and returns, leaving the 30 s refresh running.
    func start() async {
        guard !isStopped else { return }
        isStarted = true
        await refresh()
        startRefreshing(immediately: false)
    }

    /// The stop view closed or switched stop: no more fetches, and an
    /// answer still in flight is dropped.
    func stop() {
        isStopped = true
        isStarted = false
        generation += 1
        cancelRefreshing()
    }

    /// Route focus opened over the stop view.
    func pause() {
        isPaused = true
        cancelRefreshing()
    }

    /// Route focus closed: fetch now and restart the loop.
    func resume() {
        guard isPaused else { return }
        isPaused = false
        startRefreshing(immediately: true)
    }

    func scenePhaseChanged(to phase: ScenePhase) {
        switch phase {
        case .active:
            guard !isForeground else { return }
            isForeground = true
            // Back from the background: fetch now, not 30 s later.
            startRefreshing(immediately: true)
        case .background:
            isForeground = false
            cancelRefreshing()
        default:
            break
        }
    }

    /// The Retry button: fetch now and restart the loop.
    func retry() {
        startRefreshing(immediately: true)
    }

    // MARK: - Refreshing

    private func cancelRefreshing() {
        refreshTask?.cancel()
        refreshTask = nil
    }

    /// Runs the loop: a refresh first when `immediately`, else a sleep
    /// first (the caller has just refreshed). Nothing runs while stopped,
    /// paused, in the background or gone.
    private func startRefreshing(immediately: Bool) {
        cancelRefreshing()
        guard isStarted, isForeground, !isPaused, !isGone else { return }
        let clock = clock
        let interval = Self.refreshInterval
        // Weak, and strong only for one refresh: a model nobody holds ends
        // the loop at its next tick instead of being kept alive by it.
        refreshTask = Task { [weak self] in
            if !immediately {
                guard (try? await clock.sleep(interval)) != nil else { return }
            }
            while !Task.isCancelled {
                do {
                    guard let self else { return }
                    await self.refresh()
                    if self.isGone { return }
                }
                guard (try? await clock.sleep(interval)) != nil else { return }
            }
        }
    }

    /// Fetches the stop's departures. A failure keeps the last rows and
    /// sets the status. A stopped model neither fetches nor applies an
    /// answer still in flight (the view it fed is gone).
    func refresh() async {
        guard !isStopped else { return }
        let generation = generation
        let (source, stopId) = (source, target.id)
        do {
            let response = try await source.fetchDepartures(stopId: stopId)
            guard generation == self.generation, !isStopped else { return }
            info = response.stop
            departures = response.departures
            lastUpdated = clock.now()
            status = response.departures.isEmpty ? .empty : .loaded
        } catch {
            guard generation == self.generation, !isStopped, !ServerErrorText.isCancellation(error) else { return }
            Self.logger.error("Stop fetch failed: \(error.localizedDescription)")
            switch error as? TurasServerError {
            case .httpError(statusCode: 404):
                // The stop left the timetable: stale rows would mislead.
                isGone = true
                departures = []
                status = .gone
            case .httpError(statusCode: 503):
                status = .starting
            case .httpError(statusCode: 429):
                break // The next tick retries; the user never sees a rate limit.
            default:
                status = .failed(message: ServerErrorText.message(for: error))
            }
        }
    }
}
```

```swift
/// for, so the rows and scroll position stay intact and the resumed
/// fetch matches the map. Focus opened from the stop view returns to it.
@MainActor
final class HomeModel: ObservableObject {
    enum Screen: Equatable {
        case timeline
        case search
        case stop(StopTarget)
        case focus(RouteFocusTarget)
    }

    enum LocationState: Equatable {
        /// Authorisation not determined: the priming card is showing.
        case undecided
        /// Following the user's location.
        case located
        /// Not now, denied or restricted: the map started at O'Connell Bridge.
        case cityCentre
        /// Authorisation was taken away while running; the map stays put.
        case off
    }

    typealias FocusFactory = @MainActor (RouteFocusTarget, CLLocationCoordinate2D, CLLocationCoordinate2D?) -> RouteFocusModel
    /// Makes the stop view's model for a stop and the user's location.
    typealias StopFactory = @MainActor (StopTarget, CLLocationCoordinate2D?) -> StopModel
    /// Re-fetches stale route lists (StaticDataStore.refreshRoutesIfStale).
    typealias RouteRefresh = @Sendable () async -> Void

    /// O'Connell Bridge.
    static let cityCentre = CLLocationCoordinate2D(latitude: 53.3472, longitude: -6.2592)
    static let homeSpan = MKCoordinateSpan(latitudeDelta: 0.012, longitudeDelta: 0.012)

    @Published private(set) var screen: Screen = .timeline
    @Published private(set) var mode: TransportMode = .bus
    @Published var cameraPosition: MapCameraPosition = .region(MKCoordinateRegion(center: HomeModel.cityCentre, span: HomeModel.homeSpan))
    @Published private(set) var locationState: LocationState = .undecided
    /// Where the camera last settled.
    @Published private(set) var centre: CLLocationCoordinate2D = HomeModel.cityCentre
    @Published private(set) var focus: RouteFocusModel?
    /// The stop view's model. It stays while route focus is open over the
    /// stop view, which is how closing focus knows to return there.
    @Published private(set) var stop: StopModel?

    let nearby: NearbyModel
    let search: SearchModel
    let stations: StationStore

    private let location: LocationProviding
    private let makeFocus: FocusFactory
    private let makeStop: StopFactory
    private let refreshRoutes: RouteRefresh?
    private var routeRefreshTask: Task<Void, Never>?
    /// The span the camera last settled at, when the view reports it. Once
    /// the user moves the map, `cameraPosition` no longer holds a region.
    private var settledSpan: MKCoordinateSpan?
    /// Where closing the stop view or route focus puts the camera.
    private var timelineRegion: MKCoordinateRegion?
    private var hasAppeared = false
    private var isLocating = false
    private var cancellables: Set<AnyCancellable> = []
    private var focusCancellable: AnyCancellable?
    private var stopCancellable: AnyCancellable?

    init(
        nearby: NearbyModel,
        search: SearchModel,
        stations: StationStore,
        location: LocationProviding,
        refreshRoutes: RouteRefresh? = nil,
        makeFocus: @escaping FocusFactory,
        makeStop: @escaping StopFactory
    ) {
        self.nearby = nearby
        self.search = search
        self.stations = stations
        self.location = location
        self.makeFocus = makeFocus
        self.makeStop = makeStop
        self.refreshRoutes = refreshRoutes
        // Views observe this model; forward the children's changes.
        nearby.objectWillChange.sink { [weak self] _ in self?.objectWillChange.send() }.store(in: &cancellables)
        search.objectWillChange.sink { [weak self] _ in self?.objectWillChange.send() }.store(in: &cancellables)
        stations.objectWillChange.sink { [weak self] _ in self?.objectWillChange.send() }.store(in: &cancellables)
        location.authorizationStatusPublisher
            .removeDuplicates()
            .dropFirst()
            .sink { [weak self] status in self?.authorizationChanged(to: status) }
            .store(in: &cancellables)
    }

    /// Only while iOS has not been asked: an authorised user waiting for
    /// the first fix never sees it.
    var showsPrimingCard: Bool {
        locationState == .undecided && location.authorizationStatus == .notDetermined && screen == .timeline
    }

    var locationNote: String? {
        switch locationState {
        case .cityCentre: return "Showing city centre"
        case .off: return "Location is off"
        case .undecided, .located: return nil
        }
    }

    /// Whether the near-me button can do anything (when undecided, it
    /// shows the iOS prompt).
    var canLocate: Bool {
        switch location.authorizationStatus {
        case .notDetermined, .authorizedWhenInUse, .authorizedAlways: return true
        default: return false
        }
    }

    var userLocation: CLLocationCoordinate2D? { location.userLocation }

    /// A route-list refresh is running.
    var isRefreshingRoutes: Bool { routeRefreshTask != nil }

    /// The pins for the current mode: every bus stop `/nearby` returned
    /// (within 300 m of the centre), or every station of the mode once
    /// `/stations` has answered, with `/nearby`'s stops until then.
    var pins: [StopTarget] {
        if mode != .bus, let stations = stations.stations(for: mode) {
            return stations.map { StopTarget($0, mode: mode) }
        }
        return nearby.stops.map { StopTarget($0, mode: mode) }
    }

    // MARK: - Lifecycle

    func onAppear() {
        guard !hasAppeared else { return }
        hasAppeared = true
        refreshRouteListsIfStale()
        stations.load(mode)
        switch location.authorizationStatus {
        case .notDetermined:
            locationState = .undecided
        case .authorizedWhenInUse, .authorizedAlways:
            Task { await locate(movingCamera: true) }
        default:
            locationState = .cityCentre
        }
    }

    func scenePhaseChanged(to phase: ScenePhase) {
        if phase == .active {
            refreshRouteListsIfStale()
        }
        focus?.scenePhaseChanged(to: phase)
        stop?.scenePhaseChanged(to: phase)
        switch screen {
        case .focus, .stop:
            return // The timeline stays paused under them.
        case .timeline, .search:
            nearby.scenePhaseChanged(to: phase)
        }
    }

    /// Route lists older than 7 days are re-fetched at launch and when the
    /// app comes back, one refresh at a time.
    private func refreshRouteListsIfStale() {
        guard let refreshRoutes, routeRefreshTask == nil else { return }
        routeRefreshTask = Task { [weak self] in
            await refreshRoutes()
            self?.routeRefreshTask = nil
        }
    }

    /// The map camera stopped moving. In route focus the camera follows the
    /// route, and in the stop view the stop, so the timeline is left alone.
    func mapCameraSettled(centre: CLLocationCoordinate2D, span: MKCoordinateSpan? = nil) {
        self.centre = centre
        if case .focus = screen { return }
        if let span {
            settledSpan = span
        }
        if case .stop = screen { return }
        nearby.cameraSettled(at: centre)
    }

    // MARK: - Location

    /// "Allow location" on the priming card: shows the iOS prompt.
    func allowLocation() {
        Task { await locate(movingCamera: true) }
    }

    /// "Not now" on the priming card.
    func notNow() {
        locationState = .cityCentre
        cameraPosition = .region(MKCoordinateRegion(center: Self.cityCentre, span: Self.homeSpan))
    }

    /// The near-me button: back to the user's location (asking first if
    /// authorisation is still undecided).
    func goNearMe() {
        Task { await locate(movingCamera: true) }
    }

    /// Asks for a fix. Without one, a first answer falls back to the city
    /// centre; any other state keeps the map where it is.
    private func locate(movingCamera: Bool) async {
        isLocating = true
        defer { isLocating = false }
        let wasUndecided = locationState == .undecided
        if let coordinate = await location.requestLocation() {
            locationState = .located
            if movingCamera {
                cameraPosition = .region(MKCoordinateRegion(center: coordinate, span: Self.homeSpan))
            }
        } else if wasUndecided || locationState == .undecided {
            locationState = .cityCentre
            cameraPosition = .region(MKCoordinateRegion(center: Self.cityCentre, span: Self.homeSpan))
        }
    }

    /// Settings changes and "Allow Once" expiring arrive here while the app
    /// runs. The map never jumps: the timeline keeps following it.
    private func authorizationChanged(to status: CLAuthorizationStatus) {
        objectWillChange.send() // canLocate and showsPrimingCard read the status
        switch status {
        case .denied, .restricted:
            locationState = locationState == .undecided ? .cityCentre : .off
        case .notDetermined:
            if locationState == .located {
                locationState = .off
            }
        case .authorizedWhenInUse, .authorizedAlways:
            // Turned back on in Settings: refresh the fix, leave the map.
            // (A prompt answered from allowLocation or goNearMe is handled there.)
            if (locationState == .off || locationState == .cityCentre), !isLocating {
                Task { await locate(movingCamera: false) }
            }
        @unknown default:
            break
        }
    }

    // MARK: - Modes

    func selectMode(_ mode: TransportMode) {
        guard mode != self.mode else { return }
        self.mode = mode
        nearby.setMode(mode)
        search.setMode(mode)
        stations.load(mode)
    }

    // MARK: - Search

    /// The search field took focus. It shows in every state, so from route
    /// focus or the stop view the timeline comes back first and search
    /// opens over it.
    func beginSearch() {
        if case .search = screen { return }
        if case .focus = screen {
            closeFocus() // lands on the stop view when focus came from it
        }
        if case .stop = screen {
            closeStop()
        }
        screen = .search
    }

    func cancelSearch() {
        search.clear()
        if screen == .search {
            screen = .timeline
        }
    }

    /// A stop result: the stop view for that stop, as the stop's mode.
    func selectStopResult(_ stop: StopSearchResult) {
        search.clear()
        openStop(StopTarget(stop, preferring: mode), span: Self.homeSpan)
    }

    func selectPlaceResult(_ place: PlaceResult) {
        fly(to: place.coordinate)
    }

    /// A route result: focus, outbound, at the stop nearest the map centre.
    func selectRouteResult(_ route: RouteSearchResult) {
        search.clear()
        openFocus(RouteFocusTarget(route: route.ref, mode: route.mode, direction: 0, headsign: route.headsign(for: 0), stop: nil), centre: centre)
    }

    private func fly(to coordinate: CLLocationCoordinate2D) {
        search.clear()
        screen = .timeline
        cameraPosition = .region(MKCoordinateRegion(center: coordinate, span: Self.homeSpan))
    }

    // MARK: - Stop view

    /// A pin or a stop result: the stop view, centred on the stop at the
    /// user's zoom (or `span`). From the stop view, another stop replaces
    /// it; the same stop is a no-op.
    func openStop(_ target: StopTarget, span: MKCoordinateSpan? = nil) {
        if let focus {
            // Not reachable from the map in focus; keeps the state machine total.
            focus.stop()
            focusCancellable = nil
            self.focus = nil
        }
        if let stop {
            guard stop.target != target else { return }
            // Replacing a stop: the saved timeline camera still stands.
            stop.stop()
            stopCancellable = nil
        } else {
            leaveTimeline()
        }
        let model = makeStop(target, location.userLocation)
        stopCancellable = model.objectWillChange.sink { [weak self] _ in self?.objectWillChange.send() }
        stop = model
        screen = .stop(target)
        cameraPosition = .region(MKCoordinateRegion(center: target.coordinate, span: span ?? settledSpan ?? Self.homeSpan))
        Task { await model.start() }
    }

    /// Back chevron or swipe down on the stop view: the timeline, as it was.
    func closeStop() {
        guard let stop else { return }
        stop.stop()
        stopCancellable = nil
        self.stop = nil
        returnToTimeline()
    }

    // MARK: - Route focus

    /// A timeline or stop view row: focus on its route, direction and stop.
    func openFocus(departure: NearbyDeparture) {
        if let stop {
            let target = RouteFocusTarget(route: departure.routeRef, mode: stop.target.mode, direction: departure.direction,
                                          headsign: departure.headsign, stop: stop.focusStop)
            openFocus(target, centre: stop.target.coordinate)
        } else {
            let focusStop = nearby.result?.stop(withId: departure.stopId).map(FocusStop.init)
            openFocus(RouteFocusTarget(route: departure.routeRef, mode: mode, direction: departure.direction,
                                       headsign: departure.headsign, stop: focusStop), centre: centre)
        }
    }

    private func openFocus(_ target: RouteFocusTarget, centre focusCentre: CLLocationCoordinate2D) {
        if let focus {
            // Replacing a focus: whatever is saved beneath it still stands.
            focus.stop()
        } else if let stop {
            // Focus over the stop view: the stop waits, the timeline is already paused.
            stop.pause()
        } else {
            leaveTimeline()
        }
        let model = makeFocus(target, focusCentre, location.userLocation)
        focusCancellable = model.objectWillChange.sink { [weak self] _ in self?.objectWillChange.send() }
        focus = model
        screen = .focus(target)
        Task { [weak self] in
            await model.start()
            guard let self, self.focus === model, let region = model.focusRegion else { return }
            self.cameraPosition = .region(region)
        }
    }

    /// Back chevron or swipe down: the stop view when focus came from it,
    /// else the timeline, as it was.
    func closeFocus() {
        guard let focus else { return }
        focus.stop()
        focusCancellable = nil
        self.focus = nil
        if let stop {
            screen = .stop(stop.target)
            cameraPosition = .region(MKCoordinateRegion(center: stop.target.coordinate, span: settledSpan ?? Self.homeSpan))
            stop.resume()
            return
        }
        returnToTimeline()
    }

    // MARK: - Timeline camera

    /// Leaving the timeline for the stop view or focus: remember the place
    /// the rows are for, so coming back resumes a fetch for the place the
    /// map shows.
    private func leaveTimeline() {
        let span = settledSpan ?? cameraPosition.region?.span ?? Self.homeSpan
        timelineRegion = MKCoordinateRegion(center: nearby.fetchedCentre ?? centre, span: span)
        nearby.pause()
    }

    private func returnToTimeline() {
        screen = .timeline
        nearby.resume()
        if let timelineRegion {
            cameraPosition = .region(timelineRegion)
            // A no-op when the rows are for this place; otherwise (opened
            // before the first fetch) the timeline fetches here.
            nearby.cameraSettled(at: timelineRegion.center)
        }
        timelineRegion = nil
    }
}
```

```swift
import CoreLocation
import MapKit
import SwiftUI

/// The home screen: the map on the top half with the search box floating
/// over it, and the timeline, search results, the stop view or route
/// focus below.
struct HomeView: View {
    @ObservedObject var model: HomeModel
    @Environment(\.scenePhase) private var scenePhase
    /// Pin labels show when the camera is close enough to read them.
    @State private var showsPinLabels = false
    /// The camera is moving (a drag or an animation): the centre marker lifts.
    @State private var isMapMoving = false
    /// Where the camera is right now, for the radius circle; `model.centre`
    /// only updates when the camera settles.
    @State private var liveCentre: CLLocationCoordinate2D?

    private static let labelDistance: Double = 1200

    private var isInFocus: Bool {
        if case .focus = model.screen { return true }
        return false
    }

    /// The stop the stop view is showing (nil while route focus covers it).
    private var stopTarget: StopTarget? {
        if case .stop(let target) = model.screen { return target }
        return nil
    }

    /// The map shows the timeline's surroundings: marker, circle, near me.
    private var mapFollowsTimeline: Bool {
        !isInFocus && stopTarget == nil
    }

    var body: some View {
        GeometryReader { proxy in
            VStack(spacing: 0) {
                mapSection
                    .frame(height: proxy.size.height / 2)
                panel
                    .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .top)
                    .background(Theme.surface)
            }
        }
        .background(Theme.surface)
        .onAppear { model.onAppear() }
        .onChange(of: scenePhase) { _, phase in
            model.scenePhaseChanged(to: phase)
        }
    }

    // MARK: - Map

    /// Only the map runs under the status bar; the search field stays in
    /// the safe area so it never sits beneath the clock. The marker is an
    /// overlay on the map itself, so its tip is the map's true centre.
    private var mapSection: some View {
        ZStack(alignment: .top) {
            map
                .overlay {
                    if mapFollowsTimeline {
                        CentreMarker(isLifted: isMapMoving)
                    }
                }
                .ignoresSafeArea(edges: .top)
            SearchField(
                search: model.search,
                isActive: model.screen == .search,
                onBegin: model.beginSearch,
                onCancel: model.cancelSearch
            )
            .padding(.horizontal, Theme.gutter)
            .padding(.top, 8)
        }
        .overlay(alignment: .bottomTrailing) {
            if mapFollowsTimeline {
                nearMeButton
                    .padding(Theme.gutter)
            }
        }
    }

    private var map: some View {
        Map(position: $model.cameraPosition) {
            UserAnnotation()

            if isInFocus, let focus = model.focus {
                if let shape = focus.shape {
                    MapPolyline(coordinates: shape.clCoordinates)
                        .stroke(Theme.lineColor(mode: focus.mode, route: focus.route.name).opacity(0.7), lineWidth: 4)
                }
                ForEach(focus.vehicles) { vehicle in
                    Annotation(vehicle.routeId, coordinate: vehicle.coordinate) {
                        BusAnnotationView(routeId: vehicle.routeId, bearing: vehicle.bearing, mode: vehicle.mode)
                            .accessibilityLabel(AccessibilityText.vehicle(mode: vehicle.mode, routeId: vehicle.routeId, bearing: vehicle.bearing))
                    }
                    .annotationTitles(.hidden)
                }
                if let stop = focus.highlightedStop {
                    Annotation(stop.name, coordinate: stop.coordinate) {
                        StopPin(name: stop.name, showsLabel: true, isHighlighted: true)
                            .accessibilityLabel(AccessibilityText.stop(name: stop.name))
                            .accessibilityIdentifier("map.focusStop")
                    }
                    .annotationTitles(.hidden)
                }
            } else {
                if mapFollowsTimeline {
                    // The mode's radius around the marker: what the timeline looks at.
                    MapCircle(center: liveCentre ?? model.centre, radius: model.mode.nearbyRadiusMetres)
                        .foregroundStyle(Theme.brand.opacity(0.08))
                        .stroke(Theme.brand.opacity(0.35), lineWidth: 1)
                }
                ForEach(model.pins) { pin in
                    pinAnnotation(pin, isHighlighted: pin.id == stopTarget?.id)
                }
                // A stop reached by search can lie outside the pins fetched
                // for the timeline's place; it still gets its pin.
                if let target = stopTarget, !model.pins.contains(where: { $0.id == target.id }) {
                    pinAnnotation(target, isHighlighted: true)
                }
            }
        }
        .mapStyle(.standard(pointsOfInterest: .excludingAll))
        .onMapCameraChange(frequency: .continuous) { context in
            liveCentre = context.region.center
            if !isMapMoving {
                isMapMoving = true
            }
            let close = context.camera.distance < Self.labelDistance
            if close != showsPinLabels {
                showsPinLabels = close
            }
        }
        .onMapCameraChange(frequency: .onEnd) { context in
            liveCentre = context.region.center
            isMapMoving = false
            // The span lets closing the stop view or focus restore the user's zoom.
            model.mapCameraSettled(centre: context.region.center, span: context.region.span)
        }
        .accessibilityIdentifier("home.map")
    }

    /// A stop pin: tapping it opens the stop view (or switches it to this stop).
    private func pinAnnotation(_ pin: StopTarget, isHighlighted: Bool) -> some MapContent {
        Annotation(pin.name, coordinate: pin.coordinate) {
            StopPin(name: pin.name, showsLabel: showsPinLabels || isHighlighted, isHighlighted: isHighlighted)
                .onTapGesture { model.openStop(pin) }
                .accessibilityElement(children: .ignore)
                .accessibilityLabel(AccessibilityText.stop(name: pin.name))
                .accessibilityHint("Shows departures from this stop")
                .accessibilityAddTraits(.isButton)
                .accessibilityIdentifier("map.pin.\(pin.id)")
        }
        .annotationTitles(.hidden)
    }

    private var nearMeButton: some View {
        Button {
            model.goNearMe()
        } label: {
```
